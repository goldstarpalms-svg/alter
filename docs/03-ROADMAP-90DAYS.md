# 03 — Roadmap (90 days, phone-first, $50)

The goal is a personal AI self that runs on a $50 Android phone with no server.

## Phase 0 — Control plane v0.1 ✅
- Avatar, chat, local memory, audit log

## Phase 1 — v0.2 self (this release) ✅
- Real mind (Gemini via free key)
- Voice in / out (Web Speech API)
- Holo mode (self over live camera)
- Installable PWA (app shell + service worker)

## Phase 2 — Agency-lite (next)
- Tasks & reminders (already scaffolded in the Tasks tab)
- Daily digest
- Approvals / confirmations before acting

## Phase 3 — Reach
- Landing page
- First 10 users
- Launch video

## Phase 4 — Hardware (funded)
- Wrist AR HUD — full spec in `docs/04`. This is the funded phase; the engineering degree kicks in here.
